# v0.2.0

新增对齐 Apple 官方 Java Library 的 Go SDK，以及 App Store Connect 的商品管理和产物上传功能。

## 新增功能

- `appstoreserver`：以 Apple Java Library 5.2.0 为基线，提供 30 个 API 操作、请求和响应模型、枚举及独立验签接口。
- `SignedDataVerifier`：验证证书链、Apple 签名证书用途、应用标识和运行环境，支持在线 OCSP 检查。
- 优惠签名、首次订阅优惠资格签名、Advanced Commerce 请求签名和旧版 receipt 迁移工具。
- `appstoreconnect`：以官方 OpenAPI 4.5.1 为基线，提供 52 个强类型操作，覆盖应用、构建、内购商品、订阅、本地化、可售范围和价格管理。
- IPA/PKG 上传：文件预留、流式分片上传、提交和异步处理状态查询；失败时保留上传记录 ID，上传请求不附加 Connect API 的 Bearer Token。
- `signin`：独立的 Sign in with Apple 模块，新增支持 `context.Context` 的接口。
- 中文 README、兼容迁移说明、Connect 接口清单和可编译示例；Connect 生成代码可使用仓库内的官方规范子集离线重现。

## 修复与兼容性

- 限制未验签载荷中极端指数时间戳的解析开销，保留精确的整数截断。
- 保留旧版根包公开接口，新项目建议使用对应子包。
- 最低 Go 版本由 1.21.5 提升至 **1.26**，以满足当前 OCSP 依赖要求。
- API 响应保留原始 JWS；调用方需显式验签后再使用其中的数据。

## 安装

```sh
go get github.com/sunbeam27/app-store@v0.2.0
```

## 验证

已通过 Go 1.26 和稳定版 CI 的竞态测试、静态检查、构建和生成代码校验。测试覆盖官方模型与签名样本、OCSP、模拟分片上传及 receipt 解析。真实 Apple 账号和实际二进制产物上传仍需集成验证。
